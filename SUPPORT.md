# ElephantsData Support

## Product and account support

For account-specific questions, authentication problems, or matters containing sensitive information, use the official support/contact option at [elephantsdata.com](https://elephantsdata.com).

## GitHub issues

GitHub Issues may be used for:

- Documentation corrections
- General feature requests
- Reproducible user-interface problems
- Non-sensitive migration feedback

Before opening an issue, remove all credentials, tokens, email addresses, tenant identifiers, customer names, and migrated content. For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

When reporting a problem, include the source platform, destination platform, workload, expected result, observed result, and reproducible steps using test data.
